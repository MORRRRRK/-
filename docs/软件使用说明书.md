# 个人财务软件使用说明书（V3.1）

## 1. 软件简介

个人财务软件是一套 Windows 本地单机财务工具，用于记录工资、住房支出、存款、投资持仓等数据，并自动计算汇总、结余、储蓄率、投资收益率等指标。

核心特点：
- 本地 SQLite 存储，数据保存在程序目录 `data/finance.db`。
- 整个程序文件夹可复制到另一台 Windows 10/11 x64 电脑继续使用。
- 支持 Excel 导入、CSV 导出、数据库备份与恢复。
- 支持同花顺实时行情、新浪实时金价、DeepSeek/OpenAI 智能报告。
- 支持局域网只读 Web 访问。
- 支持 WebDAV 加密云同步（坚果云、Nextcloud、NAS 等）。
- 开发版与客户版都支持软件内在线更新。

## 2. 安装与启动

### 开发版
- 双击 `dist\财务软件\财务软件.exe` 启动。
- 首次启动会自动创建 `data\finance.db`、`backups\`、`exports\` 目录。

### 客户版
- 运行安装程序 `D:\Desktop\个人财务软件客户版安装程序.exe`。
- 默认安装到 `%LOCALAPPDATA%\Programs\个人财务软件客户版`。
- 安装后可直接运行，数据保存在安装目录下的 `data\`。

### 迁移到新电脑
1. 复制整个程序文件夹。
2. 或只复制 `data\finance.db` 到新程序目录的 `data\` 下。
3. 新电脑无需安装 Python 或其他环境。

## 4. 资产总览

### 功能
- 净资产：累计存款 + 投资持仓。
- 累计存款：所有月份“存款”字段合计。
- 投资持仓、累计收益、总收益率。
- 收入 / 结余 / 存款柱状图。
- 资产配置饼图（存款、基金、黄金、黄金账户、股票）。
- 汇总明细：支持按年汇总、按月汇总。

### 使用方式
- 默认显示按年汇总。
- 切换“按年汇总 / 按月汇总”可查看不同维度。
- 选择年份后，按月汇总会显示 1-12 月明细。
- 图表悬停可查看数值。

## 5. 月度流水

### 字段说明
- 月份：1-12 月。
- 月工资、年终奖、各类补贴、报销。
- 收入备注。
- 房租、水电、住房备注。
- 存款（正数=存入，负数=取出）、存款备注。
- 图片备注：双击可导入/预览/删除收入支出截图。

### 汇总
页面顶部自动计算：
- 年度工资
- 年度收入
- 住宿成本
- 理论结余
- 存款
- 储蓄率

### 其他大笔消费 / 收入
- 支持支出/收入分类。
- 支持日期范围、金额范围筛选。
- 支持新增、编辑、删除、撤销删除。

## 6. 工资参数

### 月工资 / 13薪 / 年终奖
- 月工资：按月发放的工资。
- 13薪金额、13薪月数：如 1 个月 13 薪则月数填 1。
- 年终奖金额、年终奖月数。
- 租房补贴：每月补贴金额。

### 五险一金 / 其他险种
- 每行一个险种：名称、基数、个人比例、公司比例、个人固定金额。
- 可自定义新增险种，支持六险二金。
- 删除有二次确认，支持撤销删除。

### 自动计算
- 个人缴纳合计（月）
- 公司缴纳合计（月）
- 税前总收入（年）
- 总包（年）

## 7. 持仓管理

### 分类
- 基金、黄金、股票三类。
- 渠道筛选与分类筛选。

### 持仓列表
直接在表格中编辑：
- 类别、渠道、名称、代码、资产类型
- 份额、持仓、持有收益、累计收益、收益率、成本
- 定投金额、定投时间、更新时间

### 操作按钮
- 新增持仓
- 删除选中 / 撤销删除
- 按名称解析代码
- 刷新实时行情
- 执行今日定投
- 保存修改

### 实时行情
- 使用同花顺 API Key 获取 A 股、场内基金、黄金 ETF、场外基金价格。
- 场外基金代码解析失败时自动使用东财兜底。
- 定投按交易日自动执行并计入持仓与收益。

### 无代码黄金账户
- 用于积存金、易存金等没有代码的黄金。
- 记录名称、渠道、克数、成本。
- 刷新实时金价后自动计算市值与收益。

## 8. 资产规划

### 净资产增长模拟
- 输入当前资产、每月投入、年化收益率、年数。
- 自动计算复利后的预期净资产。

### 目标倒推每月存款
- 输入目标金额、目标日期、年化收益率。
- 自动计算每月需要存入多少。

### 储蓄目标管理
- 新增/编辑/删除/撤销删除储蓄目标。
- 自动计算每月需存金额。

### 退休金测算
- 支持多段工作经历。
- 每段工作填写省份、起止年份、月缴费基数。
- 按 2024 年各省养老金计发基数估算。
- 最终以最新一份工作的结果为准。
- 可从工资参数一键填充缴费基数与个人比例。
- 测算结果仅供参考，实际以社保经办机构核定为准。

## 9. 智能报告

### 前置配置
在“设置”中填写：
- 接口地址：如 `https://api.deepseek.com/v1`
- API Key
- 模型名称：如 `deepseek-chat`

### 报告类型
- 年度报告
- 月度报告
- 持仓分析报告
- 自定义时间段

### 使用
1. 选择报告类型和时间范围。
2. 勾选“已了解并同意发送完整财务数据”。
3. 点击“生成报告”。
4. 生成结果保存到数据库，可查看历史、复制、导出 Markdown、删除与撤销。

注意：生成报告会把完整财务数据发送到所填大模型接口。

## 11. 数据安全

### 备份数据库
菜单“文件 → 备份数据库”，生成带时间戳的 `finance_YYYYMMDD_HHMMSS.db` 到备份目录。

### 恢复备份
菜单“文件 → 恢复备份”，选择 `.db` 文件后恢复，恢复前会确认。

### 导出 CSV
菜单“文件 → 导出 CSV”，导出主要表到导出目录。

### 从 Excel 导入
菜单“文件 → 从 Excel 导入”，选择 `gongzi.xlsx`，导入前自动对账，失败不会写入半成品数据。

### 加密云同步
- 数据库先加密再上传，云端只保存加密文件。
- 同步密码用于加密，忘记后无法恢复云端数据。
- 同步前自动备份本地数据库。
- 云端存在旧文件时保留冲突副本，不静默覆盖。

## 12. 局域网只读 Web

### 开启
1. 设置 → 局域网只读访问 → 启用。
2. 填写端口与访问码。
3. 保存设置后自动启动。

### 访问
- 本机：`http://127.0.0.1:8765`
- 局域网：`http://电脑IP:8765`

### Web 页面
- 总览：净资产、存款、持仓、收益、图表、汇总。
- 月度流水：按年份查看 12 个月明细与大笔收支。
- 持仓：持仓列表与黄金账户。
- 智能报告：查看已生成的报告。

### 权限
- Web 端只读，不修改任何数据。
- 需要访问码登录。
- 会话有效期 12 小时。

## 14. 外部接口一览

### 同花顺金融数据 API
- 用途：股票、基金、黄金 ETF 实时行情。
- 配置：设置 → 同花顺 API Key。
- 地址：`https://fuyao.aicubes.cn/admin/` 获取。

### 新浪财经金价
- 用途：无代码黄金账户参考金价。
- 无需 API Key。
- 获取 Au(T+D) 元/克参考价。

### 东财基金净值（兜底）
- 用途：场外基金代码解析与最新净值。
- 在同花顺接口失败或老基金无法解析时自动使用。

### DeepSeek / OpenAI 兼容大模型
- 用途：生成智能财务报告。
- 配置：接口地址、API Key、模型名称。
- 默认 DeepSeek：`https://api.deepseek.com/v1`，模型 `deepseek-chat`。

### GitHub Releases
- 用途：开发版/客户版在线更新。
- 公开仓库：`MORRRRRK/finance-releases`。
- 清单文件：`update.json`（开发版）、`customer_update.json`（客户版）。

### WebDAV
- 用途：加密云同步。
- 兼容：坚果云、Nextcloud、自建 NAS 等。
- 同步文件：`finance-encrypted.db`。

## 16. 代码结构

```
app/
  core/       数据库、路径、仓储层
  services/   计算、行情、大模型、云同步、更新服务
  ui/         界面主题、图表、主窗口、页面
  web/        局域网 Web 静态资源
tools/        迁移、打包、发布脚本
tests/        单元测试
```

### 分层原则
- `core` 只负责数据访问，不依赖界面。
- `services` 负责业务计算与外部接口，不直接操作界面。
- `ui` 负责展示与交互。
- 新增功能时优先在 `services` 增加服务，在 `ui/pages` 增加页面。

## 18. 常见问题

### 检查更新一直显示“正在检查更新…”
- 通常是网络访问 GitHub 慢或后台检查未结束。
- 已优化为先访问公开下载地址，并增加 30 秒超时提示。
- 如果仍失败，请检查网络后重试。

### 云同步提示密码错误
- 同步密码用于加密，不是 WebDAV 登录密码。
- 云端文件可能由不同密码加密，需使用同一密码。

### 忘记同步密码
- 云端加密文件无法解密，只能从本地备份恢复。

### 从云端恢复
- 会下载、解密并校验数据库完整性。
- 恢复前自动备份本地数据。

### 局域网 Web 打不开
- 检查是否启用、端口是否正确、访问码是否填写。
- 手机与电脑需在同一局域网。

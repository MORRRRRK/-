# V4 手机版开发日志

## 已实现（V4.6，桌面开发版）
- 新增消费计划：可创建多个大项计划，例如旅行、买相机、养猫等。
- 每个计划独立维护分项、计划金额、手动补录金额与备注。
- 实际花费 = 已关联记账流水金额 + 手动补录金额，自动汇总。
- 分项可勾选归集流水，支持日期范围与商家搜索。
- 支持总预算、删除二次确认与撤销删除。

## 已实现（V4.5，桌面开发版）
- 智能报告改为账单报告、工资报告、资产规划建议、综合财务报告，不再生成持仓报告。
- 报告按类型引用记账流水、工资管理和资产规划的最新结果。
- 升级数据库前自动备份旧库，开发版数据不随版本更新丢失。
- 全局括号说明改为圆形问号提示，鼠标悬停显示说明。

## 已实现（V4.4.1，桌面开发版）
- 资产总览精简：保留总额与本年度汇总，卡片放大、加分隔线，年份选择移到本年度上方。
- 记账流水新增月份快捷选择、每月强制存款独立维护、BlueCoins 格式导出。
- 修复“记支出/记收入”无反应：需先选择具体某一天，新记录加到当天末尾。
- 账户管理并入持仓管理，先建账户再添加持仓，支持按账户筛选。
- 持仓代码回车自动填充名称/资产类型/净值（同花顺）。
- 新增持仓智能分析问答，历史保留并自动压缩上下文，使用智能报告大模型配置。

## 已实现（V4.4，桌面开发版）
- 工资管理改为多工资方案标签页：新增后一直保留，关闭仅收起，重启不丢失。
- 新增“历史查询”：已收起方案可恢复，也可永久删除。
- 资产总览重做：只展示总额与 12 个月格子，点击月份查看交易明细与强制存款。
- 资产总览收支只统计导入的流水（BlueCoins 等 CSV），投资理财不混入收支。
- 修复“理论结余”把房租加回收入的错误；修复有流水时图表数据被覆盖的问题。
- 数据库新增 `salary_profiles` 表（SCHEMA_VERSION 13），旧工资数据自动迁移为默认方案。
- 手机端与服务端暂保持 V4.3.1，待桌面版确认后再同步。

## 已确认需求
- Android 优先，Flutter 技术栈，包名 `com.morr.finance`。
- 自建 FastAPI + SQLite 轻量服务端，手机与电脑通过服务端同步。
- 首版范围：开支管理、资产总览、持仓管理、设置与同步；工资税务、规划、智能报告、图片备注放后续版本。
- 手机日常使用，调试只做普通 APK 安装，不刷机、不解锁 Bootloader、不 root。
- 后续版本更新必须可以推送到手机端：手机 App 需支持服务端/发布仓库检查新版本并下载安装 APK，更新日志随版本展示。

## 环境
- 开发环境安装目录：`D:\DevTools`
- Flutter SDK、JDK 17、Android SDK、adb 均安装于此。

## 端口约定
- 同步服务固定使用 TCP `8766`，后续所有版本保持一致，客户端不需要因升级改地址。
- 局域网模式服务端绑定 `0.0.0.0:8766`，Windows 防火墙放行规则名：`个人财务软件同步服务8766`。

## 已实现（V4.0 初版）
- `finance-server`：FastAPI + SQLite，提供登录、同步推送/拉取、快照、行情代理、金价、定投执行、版本检查接口。
- `finance_mobile`：Flutter Android 应用，包名 `com.morr.finance`，含资产总览、开支管理、持仓管理、设置与同步页面。
- 桌面数据已通过 `finance-server/seed_from_desktop.py` 导入服务端，手机可离线编辑并联网同步。
- 手机端“检查更新”已接入 `/api/v1/update`，后续版本 APK 可推送到手机端安装。

## 已实现（V4.1）
- 桌面与手机版本统一为 `4.1.0`（V4.1），更新说明由服务端 `/api/v1/update` 统一下发。
- 手机端新增：工资管理（基本工资/13薪/年终奖/N险N金/专项附加扣除/个税估算）、资产规划（净资产模拟/目标存款/储蓄目标）、智能报告（服务端调用大模型生成）。

# 个人财务软件 V3.0

本地单机版个人财务软件，数据保存在程序目录 `data/finance.db`，整个程序文件夹复制到另一台 Windows 10/11 x64 电脑即可继续使用，无需安装 Python 或其他环境。

## 功能
- 月度流水：月工资、年终奖、补贴、报销、房租、水电、强制存款、大笔消费/收入，自动计算年度工资、收入、住宿成本、理论结余、存款与储蓄率。
- 月度图片备注：每月可导入收入/支出截图，双击“图片备注”单元格即可预览和删除。
- 工资参数：五险一金基数与个人/公司比例、13薪、年终奖、租房补贴可编辑，自动计算个人缴纳、税前总收入与总包。
- 持仓管理：基金/黄金/股票持仓、持有收益、累计收益、收益率、定投信息。
- 资产总览：净资产、累计存款、投资持仓、累计收益、总收益率、按年/按月汇总与资产配置。
- 资产规划：净资产增长模拟、目标倒推每月存款、储蓄目标管理。
- 设置：字体大小、主题色，保存在本地数据库中随程序迁移。
- 菜单：备份/恢复/导出/导入集中在“文件”，版本与更新内容在“关于”。
- 工资参数：各险种单独填写基数，可自定义新增险种（支持六险二金）。
- 其他大笔消费/收入：支持按日期范围、金额范围筛选。
- 界面：表格圆角化，图表上下排列，适配更大的字体。
- 实时行情：持仓填写代码、份额和资产类型后，可通过同花顺 API 刷新最新价格与持仓价值。
- 主题：支持浅色 / 深色 / 跟随系统切换。
- 图表：柱状图与饼图悬停显示数值，图表更大更清晰。
- 设置：清除导出/备份缓存、自定义导出与备份目录。
- 删除保护：所有删除都有二次确认，工资参数、持仓、储蓄目标等支持撤销。
- 持仓管理：表格直接编辑，右上角统一保存；定投按交易日自动执行。
- 持仓与黄金账户数值可直接在表格中输入，不再使用上下增减按钮。
- 图表使用原位更新，生成更快；汇总明细与月度流水直接完整显示。
- 鼠标滚轮不会改动任何下拉、日期或数值输入框。
- 老基金代码解析失败时自动使用东财兜底，行情刷新更稳定。
- 月度流水取消按钮栏与内部滚动，12 个月直接完整展示；双击图片备注仍可预览管理。
- 全局下拉菜单重绘，浅色/深色主题下都更清晰。
- 客户版在线更新：在“设置”填写 GitHub 更新仓库后，启动自动检查或点“关于 > 检查更新”。
- 更新过程保留 data/backups/exports，更新前自动备份数据库，失败可回滚。
- 无代码黄金账户：积存金、易存金按克记录，接入新浪实时金价参考。
- 智能报告：接入 OpenAI 兼容大模型，手动生成年度/月度/持仓/自定义报告。
- 报告历史：报告以 Markdown 保存，可预览、复制、导出，删除支持撤销。
- 局域网只读 Web：设置访问码后，同一局域网的手机/电脑浏览器可查看总览、流水、持仓与报告。

## 运行
双击 `财务软件.exe` 即可。首次启动会自动创建 `data/finance.db`。

开发环境运行：
```bat
call .venv\Scripts\activate.bat
python run.py
```

## 从 Excel 导入
程序内点击顶部“从 Excel 导入”，选择原来的 `gongzi.xlsx`。导入前会先对账，失败不会写入半成品数据。

命令行迁移：
```bat
python tools\migrate_xlsx.py "Z:\04文件\gongzi.xlsx"
```

## 数据安全
- 顶部“备份数据库”会复制一份带时间戳的数据库到 `backups/`。
- “恢复备份”可选择一个 `.db` 备份文件恢复。
- “导出 CSV”把主要表导出到 `exports/`。
- 迁移到新电脑：复制整个程序文件夹，或只复制 `data/finance.db` 到新文件夹的 `data/` 下。

## 实时行情
- 到 [同花顺金融数据服务](https://fuyao.aicubes.cn/admin/) 获取 API Key。
- 在“设置”中填写 API Key。
- 在“持仓管理”为每条持仓填写代码（如 `510300.SH`）、资产类型和份额，点击“刷新实时行情”或等待自动刷新。
- 股票走 A股行情快照，场内基金/黄金 ETF 走场内快照，场外基金走最新净值。
- API Key 保存在本地数据库的 `settings` 表中，仅用于请求同花顺接口。

## 智能报告
- 在“设置”填写 OpenAI 兼容接口地址、API Key 和模型名称，例如 DeepSeek、通义、Kimi 等。
- 在“智能报告”页选择报告类型和时间范围，勾选同意后手动生成。
- 生成报告会把完整财务数据发送到所填接口；接口信息只保存在本地数据库。

## 局域网访问
- 在“设置”开启“局域网只读访问”，填写端口（默认 8765）和访问码。
- 开启后本机显示 `http://127.0.0.1:8765`，同一局域网设备使用显示的局域网地址。
- Web 端只读，不修改任何数据；访问码必须填写后才能启动。

## 无代码黄金账户
- 持仓管理下方提供“无代码黄金账户”模块，可新增积存金 / 易存金账户，记录克数与成本。
- 点击“刷新实时金价”会从新浪财经获取 Au(T+D) 元/克参考价，自动计算当前市值与收益。
- 金价接口无需 API Key；仅在“刷新实时金价”或自动刷新时联网。

## 客户版发布与隐私
- 发布包只包含 `财务软件.exe`、`updater_helper.exe` 和 `_internal/`。
- `data/`、`backups/`、`exports/`、图片、数据库和 API Key 一律不进入发布包。
- 打包脚本会自动检查发布包，如果发现 `finance.db`、`data/`、`backups/`、`exports/` 等内容会直接终止并报错。
- 已启用单独的公开发布仓库 `MORRRRRK/finance-releases`，只存放发布包，不包含源码与个人数据。

发布客户版：
```bat
call .venv\Scripts\activate.bat
build.bat
build_customer.bat
python tools\package_release.py --version 3.0.0 --repo MORRRRRK/finance-releases --tag v3.0.0 --notes "更新说明"
python tools\build_customer_setup.py --version 3.0.0
set GITHUB_TOKEN=你的GitHubToken
python tools\upload_release.py --version 3.0.0
```

## 打包
```bat
build.bat
```
打包结果在 `dist\财务软件\`，包含 `财务软件.exe`、`updater_helper.exe` 和 `_internal/`。

## 开发版与客户版
- 开发版：运行 `build.bat` 生成 `dist\财务软件\`，数据保存在程序目录 `data/`，支持 GitHub 更新检查。
- 客户版：运行 `build_customer.bat` 生成 `dist\财务软件客户版\`，更新配置指向公开发布仓库，不包含 Token。
- 生成客户版安装程序：
```bat
python tools\build_customer_setup.py --version 3.0.0
```
安装程序会输出到桌面 `个人财务软件客户版安装程序.exe`，默认安装到：
`%LOCALAPPDATA%\Programs\个人财务软件客户版`
- 客户版数据与开发版完全隔离，同一台电脑可以同时运行开发和客户两版。
- 客户版支持软件内直接更新，更新只替换程序文件，已有 `data/` 自动保留。

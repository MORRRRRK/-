# V4 手机版开发日志

## 已确认需求
- Android 优先，Flutter 技术栈，包名 `com.morr.finance`。
- 自建 FastAPI + SQLite 轻量服务端，手机与电脑通过服务端同步。
- 首版范围：开支管理、资产总览、持仓管理、设置与同步；工资税务、规划、智能报告、图片备注放后续版本。
- 手机日常使用，调试只做普通 APK 安装，不刷机、不解锁 Bootloader、不 root。
- 后续版本更新必须可以推送到手机端：手机 App 需支持服务端/发布仓库检查新版本并下载安装 APK，更新日志随版本展示。

## 环境
- 开发环境安装目录：`D:\DevTools`
- Flutter SDK、JDK 17、Android SDK、adb 均安装于此。

## 端口约定
- 同步服务固定使用 TCP `8766`，后续所有版本保持一致，客户端不需要因升级改地址。
- 局域网模式服务端绑定 `0.0.0.0:8766`，Windows 防火墙放行规则名：`个人财务软件同步服务8766`。

## 已实现（V4.0 初版）
- `finance-server`：FastAPI + SQLite，提供登录、同步推送/拉取、快照、行情代理、金价、定投执行、版本检查接口。
- `finance_mobile`：Flutter Android 应用，包名 `com.morr.finance`，含资产总览、开支管理、持仓管理、设置与同步页面。
- 桌面数据已通过 `finance-server/seed_from_desktop.py` 导入服务端，手机可离线编辑并联网同步。
- 手机端“检查更新”已接入 `/api/v1/update`，后续版本 APK 可推送到手机端安装。

## 已实现（V4.1）
- 桌面与手机版本统一为 `4.1.0`（V4.1），更新说明由服务端 `/api/v1/update` 统一下发。
- 手机端新增：工资管理（基本工资/13薪/年终奖/N险N金/专项附加扣除/个税估算）、资产规划（净资产模拟/目标存款/储蓄目标）、智能报告（服务端调用大模型生成）。
- 手机端登录一次长期有效，仅清除软件缓存或退出登录后需重新登录。
- 桌面设置新增“V4 手机互联（服务器同步）”，与手机双向同步流水、持仓、黄金账户、储蓄目标。

## 已实现（V4.2）
- 新增账户管理、日常逐笔记账（支出/收入/转账）、交易分类与筛选。
- 持仓管理新增交易历史（买入/卖出/分红/定投/赎回）与 FIFO 成本收益。
- 局域网 Web 服务扩展 REST API，新增 PWA 手机记账页面（查看/快速记账/账户管理）。
- 旧 large_items 自动迁移到 transactions，迁移前自动备份数据库。
- 桌面、手机、服务端版本统一为 `4.2.0`（V4.2）。

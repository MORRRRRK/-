# 个人财务软件使用说明书（V4.2）

## 1. 软件简介

个人财务软件是一套 Windows 桌面 + Android 手机 + 局域网 PWA 的个人财务工具，用于记录日常收支、工资、五险一金、个税、持仓、黄金账户、储蓄目标，并自动计算汇总、结余、收益率、退休金等指标。

核心特点：
- 本地 SQLite 存储，数据保存在程序目录 `data/finance.db`。
- 桌面端与手机端可离线编辑，通过自建同步服务双向同步。
- 支持日常逐笔记账、多账户管理、交易分类、持仓交易历史。
- 支持同花顺实时行情、新浪实时金价、大模型智能报告。
- 支持局域网 PWA 手机记账、WebDAV 加密云同步、软件内在线更新。

## 2. 版本说明

当前统一版本为 **V4.2（4.2.0）**：
- 桌面开发版：`dist\财务软件\财务软件.exe`
- 桌面客户版：安装程序 `D:\Desktop\个人财务软件客户版安装程序.exe`
- 手机开发版：`finance_mobile\build\app\outputs\flutter-apk\app-debug.apk`
- 同步服务端：`finance-server`，默认端口 `8766`

## 3. 安装与启动

### 桌面开发版
双击 `dist\财务软件\财务软件.exe` 启动。首次启动自动创建 `data\`、`backups\`、`exports\` 目录。

### 桌面客户版
运行 `个人财务软件客户版安装程序.exe`，默认安装到 `%LOCALAPPDATA%\Programs\个人财务软件客户版`，数据保存在安装目录下的 `data\`。

### 手机开发版
- 安装 APK 到 Android 手机（可在设置中允许安装未知来源应用）。
- 手机需与电脑在同一局域网，或在 USB 调试时使用 `127.0.0.1:8766` 反向转发。
- 启动 App 后进入“设置”，填写同步服务地址并登录。

### 同步服务端
在项目目录运行：
```bat
cd /d C:\Users\49212\Documents\windows系统相关\个人财务软件
call .venv\Scripts\activate.bat
cd finance-server
python -m uvicorn server_app.main:app --host 0.0.0.0 --port 8766
```
或使用一键脚本：
```powershell
powershell -ExecutionPolicy Bypass -File "tools\start_mobile_dev.ps1"
```

### 局域网 PWA
桌面端启动并开启“局域网只读访问”后，手机浏览器访问：
```
http://电脑IP:8765/mobile/index.html
```
输入访问码后即可查看和快速记账，可在浏览器菜单中“添加到主屏幕”。

## 4. 桌面端功能

### 4.1 资产总览
- 净资产、累计存款、投资持仓、累计收益、总收益率。
- 收入/结余/存款/消费柱状图、资产配置饼图。
- 汇总明细支持按年、按月查看。
- 有账户数据时，净资产改为按账户汇总，饼图按账户统计。

### 4.2 记账流水
日常逐笔记账页面，替代旧的按月汇总编辑：
- 顶部“记支出 / 记收入 / 转账”三个快速记账按钮。
- 支持日期、分类、账户、类型、关键词筛选。
- 双击交易可编辑，支持删除、导出 CSV。
- 底部自动显示当前筛选条件下的收入、支出、结余。

### 4.3 账户管理
- 支持现金、银行卡、支付宝、微信、投资账户、信用卡、贷款、其他。
- 新增、编辑、删除账户；删除前会检查是否有关联交易。
- 自动汇总总资产、总负债、净资产。
- 信用卡/贷款账户自动视为负债。

### 4.4 历史汇总
旧版“月度流水”保留为历史数据查看入口：
- 按年份查看 1-12 月历史汇总。
- 启用日常记账后本页为只读，编辑请到“记账流水”。

### 4.5 工资管理
- 工资详情：基本工资、13薪 xN、年终奖 xN、自定义绩效/补贴（按月/季/年）。
- N险N金：每个险种单独填写基数、个人/公司比例、个人固定金额，可自定义新增。
- 专项附加扣除：租房按省-市-区选择，赡养老人、子女教育、婴幼儿照护、继续教育、房贷、大病医疗、其他扣除。
- 自动计算结果与全年个税汇总：总工资、个人/公司缴纳、税前收入、总包、全年应纳税所得额、个税、税后收入。
- 退休金测算：按工作经历分段估算，以最新一份工作为准。
- 开发版每个计算结果旁有“查看公式”。

### 4.6 持仓管理
- 持仓列表：类别、渠道、名称、代码、资产类型、净值、份额、持仓、收益、成本、定投。
- 支持“按名称解析代码”“刷新实时行情”“查看交易”。
- 黄金账户：按克记录积存金/易存金，参考实时金价。
- 持仓交易历史：买入/卖出/分红/定投/赎回，按 FIFO 计算成本与收益。
- 打开软件后自动刷新行情并按定投策略执行。

### 4.7 资产规划
- 净资产增长模拟：当前资产、每月投入、年化收益率、年数。
- 目标倒推每月存款：目标金额、目标日期、年化收益率。
- 储蓄目标管理：新增、编辑、删除、撤销删除。

### 4.8 智能报告
- 接入 OpenAI 兼容大模型（默认 DeepSeek）。
- 支持年度、月度、持仓、自定义报告。
- 报告以 Markdown 展示，可复制、导出，历史记录保存在本地。

### 4.9 设置
- 常用设置：字体大小、主题色、界面主题、同花顺 API Key、导出/备份目录、GitHub 更新仓库、源码仓库。
- V4 手机互联：填写同步服务地址和密码，登录后立即同步，桌面与手机双向同步流水、持仓、黄金账户、储蓄目标。
- 加密云同步：WebDAV（坚果云/Nextcloud/NAS），数据库加密后上传。
- 局域网只读访问：启用后手机/电脑浏览器可查看数据，PWA 页面可记账。
- 缓存清理：清除导出 CSV、备份文件等缓存。

### 4.10 关于
- 显示当前版本、更新日志。
- 开发版支持“检查更新”“推送客户版更新”。

## 5. 手机端功能（Flutter App）

手机端默认进入“功能”页，所有模块以卡片形式展示：
- 资产总览
- 开支管理
- 持仓管理
- 工资管理
- 资产规划
- 智能报告
- 设置

底部导航栏只有“功能”和“设置”。进入内部页面后，安卓返回键或侧滑返回会回到上一层。

手机端支持离线编辑，联网后手动“立即同步”即可与桌面端、服务端同步。

## 6. 数据存储与同步

- 桌面数据：`data\finance.db`。
- 服务端数据：`finance-server\finance-server.db`（不会上传到 GitHub）。
- 同步协议：行级 `updated_at` + 删除标记，服务端按最后写入时间合并。
- 同步服务固定端口：`8766`。
- USB 调试时使用 `adb reverse tcp:8766 tcp:8766` 即可用 `http://127.0.0.1:8766` 访问。
- 局域网模式使用 `http://电脑IP:8766`，需放行防火墙 TCP 8766。

## 7. 备份、恢复、导出与导入

- 备份：菜单“文件 → 备份数据库”。
- 恢复：菜单“文件 → 恢复备份”。
- 导出 CSV：菜单“文件 → 导出 CSV”，交易记录可在记账流水页单独导出。
- Excel 导入：菜单“文件 → 从 Excel 导入”。
- 交易 CSV 导入：`app/services/importer.py` 提供通用导入，支付宝/微信账单解析已预留接口。
- 历史数据迁移：运行 `python -m tools.migrate_to_transactions`，自动备份并把旧大笔消费迁移为交易记录。

## 8. 在线更新

- 桌面客户版：启动时自动检查更新，或在“关于”页点“检查更新”；更新只替换程序文件，保留 `data/`、`backups/`、`exports/`。
- 桌面开发版：可在“关于”页一键构建客户版、上传源码并发布 GitHub Release。
- 手机版：设置中“检查更新”读取服务端 `/api/v1/update`，后续 APK 发布后可推送到手机安装。

## 9. 常见问题

### 手机拔掉数据线后无法登录？
`adb reverse` 只在 USB 连接期间有效。拔线后请改用局域网地址 `http://电脑IP:8766`，并确认手机与电脑在同一 WiFi、防火墙已放行 8766。

### 登录状态很快失效？
登录 Token 保存在本地数据库，一次登录长期有效；只有退出登录或清除软件缓存才需要重新登录。

### 持仓行情刷新失败？
- 确认设置中已填写同花顺 API Key。
- 场外基金代码会自动补 `.OF`，老基金走东财净值兜底。
- 服务端模式需在 `finance-server` 的 `server_settings` 中配置同花顺 Key。

### 数据会丢吗？
不会。更新只替换程序文件，不动 `data/`；同步前会自动备份数据库。
